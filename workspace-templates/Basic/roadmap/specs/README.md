# Product Specifications Catalog

This catalog contains human-readable descriptions of what the product should do
and why. Technical architecture, code, schemas, and engineering task lists belong
in milestones or the relevant technical documentation.

**Milestone Roadmap:** [`../README.md`](../README.md)

## Specifications

### Numbering

- A specification ID must match its delivery milestone number: `Milestone 014` → `SPEC-014`.
- If a milestone has multiple specifications, use sub-numbers for all of them: `SPEC-014.1`, `SPEC-014.2`, and so on.

## Status Reference

### Requirement Status

- **Draft:** Initial content is being prepared.
- **Review:** Product decisions are being reviewed.
- **Approved:** The requirement is accepted as the current product intent.
- **Superseded:** A newer specification replaces this requirement.

### Delivery Status

- **Not Planned:** No milestone is assigned.
- **Planned:** At least one delivery milestone exists.
- **In Progress:** Implementation is active.
- **Partial:** Some approved scope is delivered.
- **Delivered:** All accepted scope is delivered.

## Relationships

- Every specification is listed in this catalog.
- Every specification links to its single delivery milestone.
- Every milestone links back to all specifications it delivers.
- Parent and related specification links are maintained in both documents when applicable.

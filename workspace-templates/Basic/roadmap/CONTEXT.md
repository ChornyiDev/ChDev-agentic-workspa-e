# Roadmap Context

## Purpose

Milestones represent complete units of product or architectural value and provide an auditable delivery history.

## Architecture

- `000_Milestone_template.md` is the source template for new milestones.
- `README.md` is the milestone index and status map.
- `specs/` contains the human-readable product specification catalog.
- Numbered milestone files contain planning, execution state, autopsy, and outcomes.
- Milestones and specifications maintain bidirectional delivery links. A specification ID matches its delivery milestone ID; multiple specifications use decimal sub-numbers such as `SPEC-014.1`.

## Current State

The base template includes milestone and specification templates with empty catalogs.

## Dependencies

- Project objectives in `AGENTS.md`.
- Product requirements under `roadmap/specs/`.
- Architecture and operational documents under `docs/`.

## Known Issues

- None in the base template.

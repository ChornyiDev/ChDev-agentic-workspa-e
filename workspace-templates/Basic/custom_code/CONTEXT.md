# Custom Code Context

## Purpose

Repository source for FlutterFlow custom Dart functions, actions, and widgets.

## Architecture

- `functions/` contains pure Dart helpers.
- `actions/` contains side-effecting operations.
- `widgets/` contains custom UI components.

## Current State

All custom-code directories are empty scaffolds in the base template.

## Dependencies

- FlutterFlow project component definitions.
- Active FlutterFlow profile in `AGENTS.md`.

## Known Issues

- Repository files and FlutterFlow editor copies can drift if changes are not synchronized.

# FlutterFlow Documentation Context

## Purpose

FlutterFlow-specific implementation notes, package mappings, MCP setup, naming references, and parameter models.

## Architecture

This directory complements `custom_code/` and `cloud_functions/` for FlutterFlow-profile projects.

## Current State

The base template includes a universal MCP setup guide.

## Dependencies

- Active FlutterFlow profile in `AGENTS.md`.
- FlutterFlow project and API access.

## Known Issues

- Remove this directory when FlutterFlow is not part of the active profile.

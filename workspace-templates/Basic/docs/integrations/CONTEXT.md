# Integration Documentation Context

## Purpose

Specifications for third-party APIs, SDKs, webhooks, authentication providers, payments, and external data flows.

## Architecture

Integration documents describe ownership, configuration variables, request and response contracts, failure behavior, and operational dependencies.

## Current State

No project-specific integration specifications are included in the base template.

## Dependencies

- Product specifications under `roadmap/specs/` and the active technology profile.

## Known Issues

- Secret values must never be stored in integration documentation.
